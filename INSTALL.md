# Installation Guide for Wake-on-LAN Manager (`wol-gui`)

This guide provides instructions for installing pre-built packages or compiling `wol-gui` from source across Fedora, Debian/Ubuntu, and Windows.

---

## 📦 Pre-Built Packages (Recommended)

Pre-built binaries and installers are available on the [GitHub Releases](../../releases) page for every release tag.

### 1. Fedora / RHEL / CentOS (.rpm)

Download the latest `.rpm` package and install it using `dnf`:

```bash
sudo dnf install ./wol-gui-0.1.0-1.fc40.x86_64.rpm
